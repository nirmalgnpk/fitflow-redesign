# Tech Stack Summary
- Mobile/Web: React Native (Expo, TypeScript) + React/Next.js
- Core backend: NestJS (Node.js, TypeScript) + Socket.IO
- AI service: Python FastAPI
- Database/cache: PostgreSQL (RDS, pgvector), Redis, S3
- Authentication: Amazon Cognito
- Hosting/DevOps: AWS ECS Fargate, CloudFront + WAF, GitHub Actions
